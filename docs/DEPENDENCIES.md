# Vendored dependencies

The project contains ordinary source files copied from the worker's preinstalled mirrors. It has no submodules, remote imports, npm dependencies or build-time network requests. The SHA-256 inventory in `dependency-sha256.json` pins every delivered dependency file.

- `lib/v4-core`: canonical Uniswap v4 PoolManager, interfaces, types, libraries and local integration test utilities. Relevant license texts are preserved under `licenses/`; each file also declares its license.
- `lib/forge-std`: Foundry test/script support, with Apache-2.0 and MIT license texts.
- `lib/solmate`: the v4 manager's Owned dependency and supporting sources, AGPL-3.0 license preserved.
- `lib/openzeppelin-contracts`: only the recursive source dependencies of ERC20, SafeERC20 and ReentrancyGuard, with the MIT license. Copied from the available 5.7.0 mirror; individual file headers identify their last change versions.

No upstream branches are fetched by the build. The exported ABI files are regenerated by `python3 scripts/check-launch.py` after an offline build.
